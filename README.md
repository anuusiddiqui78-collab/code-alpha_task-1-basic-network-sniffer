# Basic Network Sniffer

## Project Description
This project is developed as part of the CodeAlpha Cyber Security Internship.

The program captures network packets and displays useful information such as:

- Source IP Address
- Destination IP Address
- Protocol Type

## Technologies Used

- Python
- Scapy Library

## Features

- Captures network traffic packets
- Displays source and destination IP addresses
- Identifies TCP, UDP and ICMP protocols
- Helps understand basic network communication
